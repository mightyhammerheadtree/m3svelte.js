Material 3 components.
One file. No build step.

m3svelte.js is a single prebuilt JavaScript module that bundles m3-svelte together with the Svelte 5 runtime. Import it from a URL in plain HTML and you get every component — buttons, text fields, dialogs, tabs, snackbars — without npm, Vite, or Svelte compilation.

import { mount, Button } from "https://cdn.jsdelivr.net/gh/mightyhammerheadtree/m3svelte.js@main/m3svelte.js";

↑ These are real components mounted from the bundle at runtime. The switch in the header is one too — it drives this page's dark mode.

Overview

What it is. A 1.2 MB ES module built from m3-svelte@7.2.1. The component CSS is pre-processed and injected automatically, so the only things your page must provide are the Material color tokens (--m3c-*) and a handful of global tokens (shapes, elevations, font).

Why it exists. m3-svelte normally needs a Svelte + Vite toolchain plus a PostCSS mixins plugin. This file removes all of that: no install, no config, no bundler. Drop a <script type="module"> on any static page.

What's inside.

  • Svelte 5 runtime — exposed through mount, unmount and createRawSnippet.
  • 50+ components — Button, FAB, Card, Dialog, BottomSheet, ListItem, Menu, Snackbar, Checkbox, Chip, Switch, Slider, Select, TextField, DatePicker, TimePicker, progress indicators, navigation rail/bar/drawer, Tabs and more.
  • Helpers — easing curves, shared-axis animations, shape paths, badge utilities, and the Icon component for Iconify-style icons.

Good to know. Props passed to mount() are read once, since there is no Svelte compiler to make them reactive. For live updates, listen to DOM events or unmount and mount again (see Reactivity).

How to use

Four steps. The whole thing fits in one HTML file.

1

Add a theme

Components read Material color tokens from CSS variables. Paste a theme (generate one with the m3-svelte theme builder, or copy the baseline below) plus the global tokens.

<style>
  :root {
    /* colors — baseline light theme, trimmed; see Docs → Theming for the full list */
    --m3c-primary: #6750A4;  --m3c-on-primary: #FFFFFF;
    --m3c-primary-container: #EADDFF; --m3c-on-primary-container: #21005D;
    --m3c-secondary-container: #E8DEF8; --m3c-on-secondary-container: #1D192B;
    --m3c-surface: #FEF7FF; --m3c-on-surface: #1D1B20; --m3c-on-surface-variant: #49454F;
    --m3c-surface-container: #F3EDF7; --m3c-surface-container-highest: #E6E0E9;
    --m3c-outline: #79747E; --m3c-outline-variant: #CAC4D0; --m3c-shadow: #000;

    /* globals every component expects */
    --density: 0;
    --m3-font: "Google Sans Flex", Roboto, system-ui, sans-serif;
    --m3-shape-extra-small: 4px; --m3-shape-small: 8px; --m3-shape-medium: 12px;
    --m3-shape-large: 16px; --m3-shape-extra-large: 28px; --m3-shape-full: calc(infinity * 1px);
    --m3-elevation-1: 0 1px 2px 0 rgb(0 0 0 / .3), 0 1px 3px 1px rgb(0 0 0 / .15);
    --m3-elevation-2: 0 1px 2px 0 rgb(0 0 0 / .3), 0 2px 6px 2px rgb(0 0 0 / .15);
    --m3-elevation-3: 0 1px 3px 0 rgb(0 0 0 / .3), 0 4px 8px 3px rgb(0 0 0 / .15);
    --m3-easing-fast: ease 150ms; --m3-easing: ease 233ms; --m3-easing-fast-spatial: ease 383ms;
    --m3-timing-function-emphasized-decel: cubic-bezier(.05,.7,.1,1);
  }
  body { background: var(--m3c-surface); color: var(--m3c-on-surface); font-family: var(--m3-font); }
</style>
2

Import the module

Use a module script. Load from jsDelivr (shown), or download m3svelte.js and import it relatively. Pin a commit hash instead of @main for production.

<script type="module">
  import { mount, createRawSnippet, Button, Switch }
    from "https://cdn.jsdelivr.net/gh/mightyhammerheadtree/m3svelte.js@main/m3svelte.js";
</script>
3

Mount a component

mount(Component, { target, props }) renders into any DOM node. Text or markup children are passed as a snippet made with createRawSnippet.

const text = (html) => createRawSnippet(() => ({ render: () => `<span>${html}</span>` }));

mount(Button, {
  target: document.querySelector("#app"),
  props: {
    variant: "filled",            // elevated | filled | tonal | outlined | text
    onclick: () => alert("Hello from m3svelte.js"),
    children: text("Click me"),
  },
});
4

Read values back

Form components forward native attributes to their <input>, so normal DOM events work. Components that say “must be wrapped in a label” (Switch, Checkbox, Radio) simply need a <label> as the mount target.

<label id="dark"></label> Dark mode

mount(Switch, {
  target: document.querySelector("#dark"),
  props: {
    checked: matchMedia("(prefers-color-scheme: dark)").matches,
    onchange: (e) => document.documentElement.dataset.theme = e.target.checked ? "dark" : "light",
  },
});

Icons

Any prop named icon takes an Iconify icon object. Import one from @ktibow/iconset-material-symbols via a CDN, or write it inline:

import iconAdd from "https://esm.sh/@ktibow/iconset-material-symbols/add";
// …or inline:
const iconAdd = { width: 24, height: 24, body: '<path fill="currentColor" d="M11 13H5v-2h6V5h2v6h6v2h-6v6h-2z"/>' };

mount(FAB, { target: el, props: { icon: iconAdd, text: "Create", onclick: create } });

Theming

Colors are plain CSS variables named --m3c-<role> (c for color). Override them on :root, inside a media query, or on any subtree. This page swaps the whole set with <html data-theme="dark">. Roles used by the components:

Other knobs you can set globally:

VariablePurpose
--densityInteger from −3 to 0. Each step removes 4px of height from buttons, fields and list items.
--m3-fontTypeface for every component. Google Sans Flex is the M3 default; Roboto/system-ui work fine.
--m3-shape-*Corner radii: none, extra-small, small, medium, large, large-increased, extra-large, full.
--m3-elevation-0…5Box-shadow stacks used by cards, FABs, menus and dialogs.
--m3-easing*, --m3-timing-function*Motion tokens for transitions.
--m3v-backgroundTell outlined fields what color sits behind them so the label notch matches.
--m3v-bottom-offsetShift snackbars up (e.g. above a bottom nav bar).
--m3-button-shape, --m3-card-shape, --m3-dialog-shape, …Per-component shape overrides, each defaulting to a global shape token.

Reactivity

Svelte reactivity comes from the compiler, which isn't in the browser. So with mount() props are a snapshot. Two simple patterns cover almost everything:

// 1. Read state through DOM events (works for every form component)
mount(Slider, { target: el, props: { value: 30, oninput: (e) => (label.textContent = e.target.value) } });

// 2. Replace the component when inputs change
let bar = mount(LinearProgress, { target: box, props: { percent: 0 } });
function setProgress(p) {
  unmount(bar);
  bar = mount(LinearProgress, { target: box, props: { percent: p } });
}

Snackbar example

mount(Snackbar, { target: document.body });              // once
snackbar("Saved", { Undo: () => restore() }, true, 4000);  // anywhere, any time

Notes & troubleshooting

  • Nothing renders / blank. Make sure the script tag has type="module" and the page is served over HTTP(S). Check the console — a missing --m3c-* token shows up as transparent or black components rather than an error.
  • Components look squashed. --density is undefined. Set --density: 0.
  • Button has no text. children must be a snippet (from createRawSnippet), not a string.
  • Browser support. The bundled CSS uses relative color syntax (oklch(from …)) and calc(infinity*1px): Chrome 119+, Safari 16.4+, Firefox 128+.
  • Size. ~1.2 MB unminified, ~250 KB gzipped from jsDelivr. Everything is one module, so there's one request and it caches.
  • Versioning. Tracks m3-svelte@7.2.1. Pin a commit (@<sha>) for reproducible builds.
